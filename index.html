1. Project Overview & Base Template Attribution

This portfolio site will showcase my computer science coursework, software engineering projects, and technical skills. Following Option 2, I selected an open-source responsive template as a structural starting point and planned substantial layout, visual, functional, and accessibility upgrades.

Personal Developer Portfolio (4 interconnected pages: Home, About, Projects, and Contact).

3. Planned Modifications to the Base Template

To meet Option 2 criteria, the base template will be heavily customized rather than used as-is:

Comparison between the original Start Bootstrap template and my planned Capstone implementation
Aspect Original Template Planned Customization (My Capstone Site)
Site Architecture Single-page scrolling landing page with anchor links. Expanded into 4 separate HTML5 pages (index.html, about.html, projects.html, contact.html) with active-page navigation indicators.
Color Scheme & Typography Bright teal (#1abc9c) and dark navy with Montserrat/Lato fonts. Custom high-contrast Slate & Cobalt palette (WCAG AAA contrast ratios) with system-native sans-serif typography and optional Dark Mode support.
Layout & CSS Relies heavily on Bootstrap utility classes and nested divs. Refactored using semantic HTML5 landmarks (main, section, article), native CSS Grid/Flexbox, and custom responsive media queries.
Added "Extras" (Week 3) Static portfolio modals only. Adds Font Awesome icons, an interactive JavaScript project category filter, a Lightbox/Carousel preview, and a Sticky Footer.
Accessibility (WAVE) Low contrast on teal buttons and missing skip navigation link. Adds visible Skip to Main Content link, descriptive alt text, proper heading order, focus-visible rings, and prefers-reduced-motion support.

4. Visual System, Extras & Validation Checklist

Planned Accessible Color Palette

  • Deep Slate (#0F172A) — Primary text & headers (Contrast on white: 17.8:1 AAA)
  • Cobalt Blue (#1D4ED8) — Links & primary actions (Contrast on white: 6.7:1 AA/AAA)
  • Soft Cloud (#F8FAFC) — Page background surface
  • Cool Border (#CBD5E1) — Wireframe dividers & card borders

Quality Assurance Plan (Weeks 3–6)

  • W3C HTML5 Validator: Zero errors across all 4 pages.
  • W3C CSS Validator: Clean, valid external stylesheet.
  • WAVE Accessibility Tool: Zero errors, zero contrast errors, verified ARIA and heading hierarchy.
  • Cross-Device Testing: Tested in Chrome/Firefox DevTools at 375px, 768px, and 1280px viewports.
